# Code of conduct

VPS Buddy is built for a professional, inclusive security community.

Contributors must be respectful, assume good faith, accept constructive review, and avoid harassment, discrimination, threats, doxxing, or publication of another person's sensitive information. Security research discussed in this project must be authorized and framed around defensive benefit.

Project maintainers may edit or remove contributions and restrict participation when behavior harms the community or project. Serious or sensitive conduct concerns should be reported privately to the CodeJavu organization rather than posted in a public issue.

By participating, you agree to follow these expectations in project spaces and when publicly representing the project.
