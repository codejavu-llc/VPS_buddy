# Authors and maintainers

VPS Buddy was created in 2021 by [Moein (`@moein9`)](https://github.com/moein9) as a practical VPS bootstrap script for bug-bounty researchers.

VPS Buddy 3.0 was redesigned and is maintained as a [CodeJavu LLC](https://github.com/codejavu-llc) security project, with contributions recorded in the Git history.

Thank you to every upstream tool maintainer whose work makes the security ecosystem possible. VPS Buddy installs those projects but does not claim ownership of them; each remains subject to its own license and policies.
